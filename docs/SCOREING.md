# ReadySignal Scoring Philosophy

The Signal Score exists to rank opportunities, not to predict outcomes.

A high score means:

- Strong ICP fit
- High-quality contact
- Good timing
- Relevant context

It does NOT guarantee a meeting.

Every scoring rule should be understandable and explainable.

The SDR should always be able to ask:

"Why did ReadySignal rank this person highly?"

...and receive a transparent answer.
